# OpenClaw 国内 API 配置指南

本仓库提供 OpenClaw 配置国内版 LLM API 的快速指南，帮助用户快速将 OpenClaw 切换到国内 API 服务商。

## 支持的 API 服务商

- **MiniMax**: https://www.minimaxi.com
- **智谱 AI (GLM)**: https://bigmodel.cn

## 快速开始（推荐）

运行配置向导，一键完成配置：

```bash
openclaw onboard
```

按提示选择服务商、输入 API Key、选择模型即可。

详细教程见：[OpenClaw 国内 API 配置指南](./OPENCLAW-CN-API-GUIDE.md)
